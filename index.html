01 / sobre mí

Código sólido, equipos que avanzan

Soy desarrollador de software especializado en Oracle APEX y PL/SQL. Trabajo en el diseño, construcción, mantenimiento y optimización de aplicaciones críticas y bases de datos corporativas, desde el levantamiento de requerimientos hasta el despliegue en producción.

02 / fortalezas

Más allá del código

Mi base es PL/SQL y Oracle APEX, pero también aporto en la forma en que el equipo trabaja y entrega.

Liderazgo técnico y mentoría

Acompaño a los desarrolladores nuevos del equipo: les explico la base de código, resuelvo dudas técnicas y les enseño los estándares del proyecto para que lleguen antes a ser autónomos.

Control de versiones y code review

Gestiono repositorios en Git y GitHub: ramas, pull requests y revisión de código para mantener la calidad y la trazabilidad de cada cambio.

Despliegues y gestión de ambientes

Automatizo despliegues diarios con Shell y CLI, y configuro y homologo servidores y flujos en los ambientes DEV, QA, UAT y PROD.

Contraparte técnica con el cliente

Levanto requerimientos funcionales directamente con el cliente y los convierto en soluciones técnicas concretas. Hago de puente entre el negocio y el desarrollo.

Desarrollo asistido por IA

Integro herramientas de IA, como Claude en VS Code, al flujo de desarrollo para entregar funcionalidades más rápido, sin dejar de lado la revisión ni las buenas prácticas.

Metodologías ágiles

Trabajo con SCRUM: planificación por sprints, entregas incrementales y coordinación constante con el equipo y con las contrapartes.
